🔄 Sync - Google Sheets

Your own deployment - data goes only to your Sheet. Works fully offline; sync is an enhancement.
🩺 Connection troubleshooting
  • The URL must be the Web app URL ending in /exec - not the /dev URL or the script editor link.
  • Deployment "Who has access" must be Anyone ("Only myself" always fails from the browser - it can't sign in to Google). Change it via Deploy → Manage deployments → ✏️ Edit → Who has access: Anyone → New version. The URL stays the same.
  • Self-test: open the /exec URL directly in a new browser tab - you should see JSON like {"ok":true,…}. A Google sign-in page means the access setting is wrong.
  • The first request after deploying can take several seconds (cold start) - just Test connection again.

📋 One-time Sheet setup (~10 min)
  1. Create a Google Sheet named "Finance Tracker".
  2. Extensions → Apps Script → delete the default code → paste the code below → Save.
  3. Deploy → New deployment → type Web app → Execute as: Me → Who has access: Anyone → Deploy.
  4. Why "Anyone"? The browser can't attach your Google login to sync requests, so "Only myself" makes every request fail. The long /exec URL is effectively your secret key - don't share it.
  5. Authorize with your Google account → copy the Web app URL.
  6. Paste it in Settings → Sync → Test connection → expect 🟢. Tabs auto-create on first push.
  7. If you ever edit the Apps Script: Deploy → Manage deployments → edit → New version. The URL stays the same.
  8. Phone: open this same file in Chrome → ⋮ → Add to Home Screen → paste the same URL in Settings → Sync → both devices sync via the Sheet.
